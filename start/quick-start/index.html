Quick start

This program creates a worker, binds a queue to it and adds two jobs. Press Run to run it on the Go Playground. Press Edit to change it, then Run again (or Ctrl+Enter, Cmd+Enter on a Mac).

Tab inserts a tab. Esc leaves the editor. Ctrl+Enter runs.



It prints Processing 1, then Processing 2 once the first job’s one-second sleep is over, then Program exited.


Line by line
Section titled “Line by line”




NewWorker builds a worker around a function that handles one job. The job type is generic: a Job[int] carries an int, which Data() returns. With no concurrency argument the worker runs one job at a time, which is why Processing 2 waits for the first job to finish.




WaitUntilIdle blocks until the worker has no jobs left and is idle. Deferring it holds main open until both jobs are done. Without it, main would return straight after the two Add calls and the program would exit before the jobs ran.




BindQueue creates a first-in, first-out queue and binds it to this worker. Jobs added to it go to this worker and no other.




Add puts a job in the queue and returns at once, without waiting for the job to run. It returns a handle to the job and true, or false if the queue did not take the job (it is full or closed, for example). This example ignores both.
