Worker pools and job queues for Go

Add jobs to a queue. A pool of workers runs them. Keep the jobs in memory, or in Redis or SQLite so they survive a restart.

    JOB 02Where jobs livememory, SQLite or Redis
    Same worker. You choose where the jobs live.
    Press Restart process. A queue in memory ends with the process. A queue in Redis or SQLite keeps the waiting jobs.
    Built in. Plain queues, priority queues and topics live in your process. They have nothing to set up, and they end when the process ends.
    main.goQueues guide
    queue := worker.BindQueue()

// or, ordered by a number:
pq := worker.BindPriorityQueue()
    Use it when a lost job is fine, or when you can add it again.
    sqliteq keeps jobs in local SQLite files, so a single process keeps them across a restart with no server to run.

    redisq keeps jobs in Redis. A persistent queue lets one process keep its jobs across a restart. A distributed queue lets several processes consume one queue, and each job goes to one of them.

    What the same run says against VarMQ
    • Memory. VarMQ allocates 115 MB per 1M tasks. ants allocates 15 MB, which is 7.5× less. Add never blocks, so waiting tasks sit in an unbounded queue.
    • One worker. On the 15 one-worker Loop10 rows, a plain buffered channel is fastest in all 15.
    • 4 CPUs. The buffered channel wins 21 of 55 rows and VarMQ wins 19. At 24 CPUs VarMQ wins 39 and the channel 12.
    • Redis, one producer. rmq leads 12 of the 13 single-producer rows. VarMQ leads the enqueue-only row, and leads the 100-producer rows with one instance at 100 and 1,000 workers.

    package main

import (
	"fmt"
	"time"

	"github.com/goptics/varmq"
)

    func main() {
	worker := varmq.NewWorker(func(j varmq.Job[int]) {
		fmt.Printf("Processing %d\n", j.Data())
		time.Sleep(1 * time.Second)
	}) // default concurrency is 1
	defer worker.WaitUntilIdle()
	queue := worker.BindQueue()

	queue.Add(1)
	queue.Add(2)
}

import (
	"fmt"

	"github.com/goptics/varmq"
)

    func main() {
	// Not started, so all three jobs wait in the queue together.
	worker := varmq.NewWorker(
		func(j varmq.Job[string]) {
			fmt.Println("running", j.Data())
		},
		varmq.WithAutoRun(false),
	)

	queue := worker.BindPriorityQueue()

	queue.Add("report", 10)
	queue.Add("alert", 1)
	queue.Add("digest", 10)

	worker.Start()
	worker.WaitUntilIdle()
}

    package main

import (
	"fmt"

	"github.com/goptics/varmq"
)

    func main() {
	worker := varmq.NewWorker(
		func(j varmq.Job[string]) {
			fmt.Println(j.Data())
		},
		varmq.WithStrategy(varmq.RoundRobin),
		varmq.WithAutoRun(false),
	)

	alerts := worker.BindQueue()
	reports := worker.BindQueue()
	emails := worker.BindQueue()

	alerts.Add("alert 1")
	alerts.Add("alert 2")
	reports.Add("report 1")
	emails.Add("email 1")
	emails.Add("email 2")
	emails.Add("email 3")

	worker.Start()
	worker.WaitUntilIdle()
}

    Two workers subscribe to one topic, and each gets every order. Read it in the docs
    topic-subscribe/main.go
    9 lines: package and imports
    package main

import (
	"fmt"
	"time"

	"github.com/goptics/varmq"
)

    func main() {
	topic := varmq.NewTopic[int]()

	email := varmq.NewWorker(func(j varmq.Job[int]) {
		time.Sleep(500 * time.Millisecond)
		fmt.Println("email for order", j.Data())
	})

	stock := varmq.NewWorker(func(j varmq.Job[int]) {
		time.Sleep(10 * time.Millisecond)
		fmt.Println("stock for order", j.Data())
	}, 2)

	email.WithTopic(topic)
	stock.WithTopic(topic)

	for i := range 4 {
		topic.Publish(i) // both workers get their own job for this order
	}

	email.WaitUntilIdle()
	stock.WaitUntilIdle()
}

    A result worker returns a value and an error, which you read from the job. Read it in the docs
    worker-types-result/main.go
    9 lines: package and imports
    package main

import (
	"fmt"
	"strconv"

	"github.com/goptics/varmq"
)

    func main() {
	worker := varmq.NewResultWorker(func(j varmq.Job[string]) (int, error) {
		return strconv.Atoi(j.Data())
	})
	queue := worker.BindQueue()

	for _, s := range []string{"42", "forty-two"} {
		job, _ := queue.Add(s)
		n, err := job.Result()
		fmt.Printf("%q: %d, %v\n", s, n, err)
	}
}
