This table compares varmq with [ants](https://github.com/panjf2000/ants), [pond v2](https://github.com/alitto/pond), [conc](https://github.com/sourcegraph/conc), [workerpool](https://github.com/gammazero/workerpool), [errgroup](https://pkg.go.dev/golang.org/x/sync/errgroup) and [gopool](https://github.com/bytedance/gopkg/tree/main/util/gopool). It is the same table as the feature comparison in the [README](https://github.com/goptics/varmq#feature-comparison).

| Feature                                  | varmq | ants | pond  | conc | workerpool | errgroup | gopool |
| ---------------------------------------- | :---: | :--: | :---: | :--: | :--------: | :------: | :----: |
| Generic (type-safe) API                  |  Yes  | Yes  |  Yes  | Yes  |     No     |    No    |   No   |
| Tasks return results and errors          |  Yes  |  No  |  Yes  | Yes  |     No     |   No²    |   No   |
| Task groups (submit many, wait once)     |  Yes  |  No  |  Yes  | Yes  |     No     |   Yes    |   No   |
| Priority queue                           |  Yes  |  No  |  No   |  No  |     No     |    No    |   No   |
| Persistent queues (survive restarts)     |  Yes  |  No  |  No   |  No  |     No     |    No    |   No   |
| Distributed queues (across instances)    |  Yes  |  No  |  No   |  No  |     No     |    No    |   No   |
| Several queues bound to one pool         |  Yes  |  No  | Yes⁴  |  No  |     No     |    No    |   No   |
| Topic fan-out (publish once, many pools) |  Yes  |  No  |  No   |  No  |     No     |    No    |   No   |
| Bounded queue, reject when full          |  Yes  | Yes  |  Yes  |  No  |     No     |   No³    |   No   |
| Pause and resume                         |  Yes  |  No  |  No   |  No  |    Yes     |    No    |   No   |
| Restart after stop                       |  Yes  | Yes  |  No   |  No  |     No     |    No    |   No   |
| Resize pool at runtime                   |  Yes  | Yes  |  Yes  |  No  |     No     |    No    |  Yes   |
| Cancel work via context                  |  Yes  |  No  |  Yes  | Yes  |     No     |   Yes    |   No   |
| Panic recovery                           |  Yes  | Yes  |  Yes  | No¹  |     No     |    No    |  Yes   |
| Task counters (submitted, failed, ...)   |  Yes  |  No  |  Yes  |  No  |     No     |    No    |   No   |
| Built-in REST API                        |  Yes  |  No  |  No   |  No  |     No     |    No    |   No   |

Checked against each package's source, October 2026.

1. conc re-raises a task's panic from `Wait` by design.
2. errgroup returns the first error, no results.
3. errgroup has no queue; `TryGo` only refuses a task while every slot is busy.
4. pond subpools: each has its own queue and runs on the parent pool's workers.

For how fast each one runs, see the [benchmarks](https://github.com/goptics/benchmarks) and the [bench log](https://varmq.goptics.org/bench-log/).
