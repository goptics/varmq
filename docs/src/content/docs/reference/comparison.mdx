## What this page leaves out

This table covers in-process worker pools only. The [benchmarks](/reference/benchmarks/) also measure Redis job queues (Asynq, gocraft/work, rmq, taskq) and SQLite job queues (goqite, Backlite, River). This page has no feature table for them.

For how fast each one runs, see the [benchmarks](/reference/benchmarks/), with the raw data in [goptics/benchmarks](https://github.com/goptics/benchmarks), and the [bench log](https://varmq.goptics.org/bench-log/).
